# 096. 爬楼梯

## 题目

每次爬 1 或 2 阶，求到第 n 阶的方法数。

## 最优思路

经典 DP。dp[i]=dp[i-1]+dp[i-2]，只依赖前两项，用两个变量滚动优化。

## 关键点

- 先明确状态/指针/边界含义，避免靠试错写分支。
- 面试中要主动说明为什么该做法不会漏解或重复。
- 写完后用空输入、单元素、重复值、边界值各过一遍。

## 复杂度

时间 O(n)，空间 O(1)。

## JavaScript 题解

```js
function climbStairs(n) {
  let a = 1, b = 1;
  for (let i = 2;i <= n;i++) {
    [a, b] = [b, a + b];
  }
  return b;
}
```
