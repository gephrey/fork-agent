# 045. 链表相交

## 题目

找两个链表的第一个相交节点。

## 最优思路

双指针分别走 A、B，到尾后切到另一条链表。若相交，两指针会在相交点相遇；不相交则同时为 null。

## 关键点

- 先明确状态/指针/边界含义，避免靠试错写分支。
- 面试中要主动说明为什么该做法不会漏解或重复。
- 写完后用空输入、单元素、重复值、边界值各过一遍。

## 复杂度

时间 O(m+n)，空间 O(1)。

## JavaScript 题解

```js
function getIntersectionNode(a, b) {
  let p = a, q = b;
  while (p !== q) {
    p = p ? p.next: b;
    q = q ? q.next: a;
  }
  return p;
}
```
