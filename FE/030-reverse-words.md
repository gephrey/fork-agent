# 030. 反转字符串中的单词

## 题目

去掉多余空格后反转单词顺序。

## 最优思路

先 trim，再按连续空白切分，反转数组后 join。面试若要求原地，可先整体反转再逐词反转。

## 关键点

- 先明确状态/指针/边界含义，避免靠试错写分支。
- 面试中要主动说明为什么该做法不会漏解或重复。
- 写完后用空输入、单元素、重复值、边界值各过一遍。

## 复杂度

时间 O(n)，空间 O(n)。

## JavaScript 题解

```js
function reverseWords(s) {
  return s.trim().split(/\s + /).reverse().join(' ');
}
```
